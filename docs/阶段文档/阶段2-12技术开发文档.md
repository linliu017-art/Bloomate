# 阶段2-12技术开发文档：到期与恢复影响展示

## 目标
依据 PRD V3 3.2a：习惯周期未开始、进行中或到期应明确显示；到期仅进入待复盘，不自动完成或开花。暂停恢复和未来周期调整预览应显示截止日期、未来计划日、已完成次数与用户已确认的阶段标准，帮助用户判断影响；不自动延长、不更改标准、不自行归档或开启新阶段。历史记录与原提案保持不变。

## 接口和数据
不增加表，GET 习惯阶段根据阶段时区当前日期返回 upcoming/active/review_due；暂停状态读取返回已有截止日期、未来计划日及可追溯成长计数与标准。周期调整预览增加计划日数量及当前标准和已完成次数；明确未来计划数不包含今天、补签窗口或已完成的事实，不能据此错误断言一定能否达标。旧提案无新增字段也可读取，接口向后兼容。

## 验证
mock 测试时区边界、到期不自动完成、暂停恢复保持标准与数据、预览不更改正式周期、旧提案兼容；真实 DeepSeek 虚构习惯创建→阶段设定→暂停→查看恢复影响→恢复；浏览器桌面和390px验证；verify 阶段2-12及证据包。本机不对外试用。多周期管理、成果复盘和收藏属于后续阶段。

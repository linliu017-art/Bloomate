# 阶段2-7技术开发文档：今日行动与目标排期

## 目标与范围
按 PRD V3 FR03 与第二轮行动范围，用户可以为已确认目标步骤显式选择或清除计划日期，首页按北京时间展示今天与已逾期的未完成目标步骤，以及今天已确认周期的习惯计划日。未指定日期不能推定为今天，暂停中的目标与暂停日不列入应做；完成状态和已保存的计划不得丢失。本阶段不代替正式用户的可配置时区，习惯日期沿用阶段时区；不实现新增、删除目标步骤及整目标完成收藏。

## 数据与接口
增量为 `goal_action_states` 增加 `due_date` 可空日期字段（用户明确选择）；原数据默认无日期。沿用唯一键与事务，完成、撤销和日期操作互不覆盖。`PUT /api/v1/plants/{id}/actions/{index}/date` 接受有效日期或null，返回步骤及当前完成和日期；归属、类型、索引严格验证。目标调整建议基准指纹包含日期，避免日程被修改后旧提案覆盖新状态。`GET /api/v1/today` 聚合目标今天和逾期未完成步骤及未暂停习惯今天计划日；未安排的目标步骤以独立栏目展示，不宣称为今天。习惯今天按其周期时区判定，暂停时过滤。所有读取只读、不写、不伪造日期。用户操作才能修改正式数据。

## 验证
自动化测试时间边界、无日期、今天和逾期、完成排除、设置与清空日期、并发覆盖保护、调整提案的日期冲突、目标及习惯暂停过滤、时区、归属和重启恢复。复用已有真实 DeepSeek 目标与习惯生成、确认种植、设置日期及今日聚合的完整路径；桌面和390px测试，统一 verify 与独立证据包。继续保持本机运行；AI主动针对习惯调整和成长完整份额规则仍需继续实现，不属于本子阶段。

# Bloomate 首版开发轮次

状态：五轮顺序和范围已由产品经理确认（2026-10-31）；阶段 1 的技术适配三项确认仍待完成。每轮开始前单独细化技术开发文档与任务，不在本阶段编码。每个适用开发子阶段需真实模型冒烟、自动测试、构建、恢复检查和产品经理验收；无真实 Key 时未完成。

1. 第一次种植：目标/习惯双入口、AI 澄清及计划提案、用户确认、持久化第一株、手机网页最小交互。验收：两条入口各跑通提案、确认、种植，重启恢复；只在本机受控验证。
2. 行动、调整与成长：今日任务、完成和撤销、习惯计划日打卡及最近 3 天补签、轻反馈；AI 调整前后预览与确认、暂停恢复、阶段标准由用户确认、阶段成果驱动成长。验收：记录一致、不重复记账、未经确认不改变正式计划、暂停恢复保留积累，重启恢复。
3. 花园与园丁陪伴：花园植物查看、明确目标完成确认与整株收藏、习惯阶段收藏与同株继续、花种及必要装饰；授权记忆的查看修改删除、连续错过两次计划行动后的站内关心、频控与关闭选项。验收：收藏可回看，奖励不重复且撤销时资格正确；无授权不记，留言不重复，不自动改计划。
4. 账号与数据保护：游客 7 天保留和到期提示/清理、注册保存与安全迁移、登录隔离、个人数据删除。验收：用户数据互相隔离，迁移幂等且无丢失，到期和删除按规则生效；对外试用前全部通过。具体登录方式、服务商规则、删除及备份细节届时决定。
5. 正式界面与全流程：完善绘本风、响应式页面、可用性和完整流程。验收：手机及桌面操作、两条完整路径、真实样例和恢复验证通过，用户亲自验收。

上线与收尾在上述之后，按用户要求暂不安排。每轮可再拆成子阶段，按阶段规则不能一次开发所有阶段。模型真实验证前报价，测试期间 50 元/月预算上限，服务商及数据处理条款另行核实。花种、装饰和具体成长细节须在相关轮次前确认。

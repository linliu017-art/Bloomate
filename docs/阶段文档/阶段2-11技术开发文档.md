# 阶段2-11技术开发文档：目标成长份额

## 目标与边界
依据 PRD V3 3.2、FR07：目标有固定总量的进度份额，完成步骤获得份额只作为轻反馈；阶段成长仍须明确标准及用户确认，100%不自动代表目标完成。具体权重规则尚未冻结，本阶段采用透明的临时默认：初始步骤均分总额；已完成份额固定保留，拆分未完成步骤时子步骤合计继承原份额，新增/取消/恢复未完成步骤只在未赚取份额之间重新均分；已完成步骤撤销时回退其份额。百分比仅是计划内部进度，不代表真实目标已完成。

## 数据与兼容
使用精确分数的分子/分母字符串保存 `goal_action_weights`，避免浮点累积误差；按 owner、plant、索引唯一。第一轮已有目标首次迁移时按当前已确认步骤等分，已完成状态保留；为避免旧数据丢失只增加表，不重写旧计划。新增目标确认时创建；新增/拆分/取消/恢复/完成/撤销在数据库事务内同步维护。没有待完成步骤时保留未分配余额，不能伪造已赚取份额。老确认、周期、进度和模型接口保持兼容。不同用户不能互相读写，现阶段固定主体仅本机。

## 验收
离线测试初始均分、完成/撤销、拆分前后份额总和、已赚取进展不因拆分或新增减少、取消恢复、全取消与新增、重复操作、旧目标迁移、同事务重启恢复及错误；真实 DeepSeek 虚构目标确认、步骤完成、拆分确认、读回份额不下降；桌面和390px页面检查；扩展重启钩子并运行 verify 阶段2-11。默认规则须标注暂定，后续产品验收可调整，不能当作最终商业指标。

# 阶段2-8技术开发文档：习惯遇阻建议

## 目标及边界
依据 PRD V3 FR04、FR12，用户描述习惯困难时，由园丁针对已确认的周期和完成记录提出一条文字建议；不修改任何正式周期、完成标准、时区或既有打卡。用户可以在现有未来周期调整界面自行选择新日期与星期，先预览前后差异，再明确确认；也可忽略建议。AI 不可直接提交、取消、暂停或完成。已完成记录不删除；开始日期、时区和单次完成标准的调整暂不支持，不将建议称为系统已变更。

## 数据与接口
复用既有 DeepSeek 生成通道、密钥、预算和超时重试。新增带 owner、plant、status、困难文字和建议文字的持久化任务，待完成任务重启转为中断错误。`POST /api/v1/plants/{id}/habit-advice` 输入困难，只有已确认周期的本人习惯可发起，后台生成结构校验的单条建议；`GET /api/v1/habit-advice/{id}` 查询 pending/running/done/error。前端保存当前建议任务标识，刷新后可以恢复；建议可编辑，仅作参考；未来周期修改仍使用已有提案和确认接口。

## 验证
mock 回归任务、无周期、本人隔离、模型超时和失败、建议不改周期、刷新恢复、确认前后与历史不变、版本冲突；真实 DeepSeek 虚构习惯遇阻产生建议并验证正式周期未改变，用户再独立预览和确认未来调整；重启钩子保留已生成建议及周期提案；桌面和390px浏览器测试，执行 `verify.sh Bloomate 阶段2-8`。预算及服务商隐私沿用现有决定，本机验证、不上云。

# 技术适配声明

状态：产品经理于 2026-10-31 确认三项；阶段 1 仅产出文档。

## 1. 产品形态判断
- 用户与任务：中国大陆小范围成年试用者，通过 AI 园丁将明确目标或长期习惯转化为计划，并用花园记录进展。
- 核心交互：多轮对话、计划预览与用户确认、种下第一株植物；未注册前提示未保存到账户。
- 开发路径：纵向切片。对话、确认和种植反馈决定核心体验，需要真实交互才能评价。
- 验收界面：可保留至正式产品的最小手机 Web 界面，需产品经理确认。从出现起检查桌面及手机宽度，并进行类型检查、Lint 和生产构建；后续可根据反馈迭代外观。
- 上线环境：用户已有云开发环境，计划复用；环境及额度上线阶段核实。当前不创建云资源，不安排部署。
- 当前阶段：技术适配声明及确认，不写产品代码。
- 首个开发子阶段的建议边界：目标或习惯的基本输入与澄清、结构化计划提案、用户明确确认、持久化第一株植物和基本成长展示；重新打开后可恢复。提供清晰的游客提示；完整注册迁移和七天过期清理在相应后续子阶段实现，在它们完成前只限本机受控验证，不对外试用或声称游客保留承诺已兑现。
- 产品经理已确认五轮：1 第一次种植；2 行动、调整与成长；3 花园与园丁陪伴；4 账号与数据保护；5 正式界面与全流程。具体范围与验收见 tasks/plan.md；每轮可再拆成子阶段，这些暂缓功能不从首版删除。

## 2. 采用的默认方案
- Python 3.12、FastAPI、Pydantic 和 pytest：提供业务接口、结构化校验和自动测试。
- 手机优先的 Next.js、TypeScript 和 Tailwind：支持正式网页与可保留的最小交互；桌面和移动宽度均验收。
- 本地 SQLite 持久化，数据访问集中管理：支持计划、确认和植物跨重启恢复，为后续部署保留适配空间。
- 模型通过服务端调用，厂商待真实测试前结合成本和数据处理条款选择；模型结果结构校验，失败、超时和有限重试均由代码处理。
- Git 与忽略规则：已初始化并验证 .env 类路径被忽略；阶段 0 脚本密钥扫描通过，但不等于绝对排除所有泄露。

## 3. 按需模块
- 关系数据库和迁移：目标、计划、用户数据和确认记录触发；第一切片从必要实体开始。
- 流式展示：若首个切片采用流式接口，结束必须发送 done 或 error；不依赖流式展示才能验证时可以暂缓。
- 定时检查与站内关心：用户已确认主动关心，后续子阶段按持久化、幂等和频率限制实现。
- 游客主体隔离、过期与迁移：注册保存和隐私规则触发；首次对外试用前必须实现并验证。
- 不引入知识库、日历笔记集成、复杂游戏经营或多 Agent；这些未被首个闭环触发。

## 4. 偏离或暂缓
- 完整正式界面与绘本视觉系统：先做保留到正式产品的最小交互，避免在核心体验未验证前铺开；需确认不影响首轮验收。
- 注册、游客迁移、游客过期清理、个人数据删除、主动关心与完整收藏：首个切片暂缓，后续首版实现。首个切片仅本机受控验证，不能作为对外试用版本。
- 云部署与计费：用户要求暂缓，上线前核实既有环境和费用；不在本阶段创建或修改云资源。
- 对话及模型数据可能发送至所选模型服务商；选择服务商前核实处理条款与费用。不得把中国大陆试用用户等同于数据处理一定在中国大陆。

## 5. 强制底线检查
- 密钥与隐私：待实现；密钥只放被忽略的环境文件，限制日志内容，服务商规则待核实。
- 数据与任务可恢复：待实现；第一切片验证重启后计划、确认和植物状态恢复。
- 输入输出与接口：待实现；模型输出结构校验，接口统一错误结构。
- 错误与日志：待实现；超时、失败及 SDK 初始化异常有兜底，不暴露堆栈或记录完整用户文档。
- 高风险操作：计划变更与种植由明确用户确认触发，确定性代码校验并写入；模型不自主决定最终状态。
- 测试与真实模型验收：先自动测试，再用真实 Key 冒烟并以 5–10 条真实样例评分；无 Key 时阶段未完成。测试期间模型预算上限 50 元/月，调用前估价并建立用量控制，具体额度保护依服务商能力核实，无法保障时停止调用。
- 上线权限与隐私：服务端用户隔离、游客过期与删除、迁移安全、数据处理规则和恢复均须在对外试用前实现验证。

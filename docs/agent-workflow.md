# 园丁 Agent：创建到执行

当前源码包含对话查询、目标/习惯草案创建、目标改期/拆小，以及完成、撤销、习惯打卡/补签更正、暂停恢复和达标后结束。手动今日行动、打卡、花园、收藏和花种图鉴全部保留。

## 操作流程

描述目标或习惯 → 补充条件 → 编辑并确认种植 → 执行行动 → 报告实际完成 → 核对具体对象和日期 → 确认记录 → 成长与收藏同步。对象不明确时先选择；未完成、不确定的表述不会自动写打卡。周期和下一阶段通过原植物表单预览确认。

## 编排与持久化

- `backend/app/agent.py`：意图结构校验、本人上下文、持久化会话/请求与处理状态，受现有模型超时、有限重试和预算约束。
- `agent_planning.py`：待确认新计划草案；`agent_changes.py`：目标步骤日期/拆分；`agent_records.py`：执行记录及生命周期适配，复用原业务事务。
- 选择来源、版本、任务/阶段/日期及原状态摘要由后端验证；模型不提供内部身份或决定权限。确认与业务效果原子持久化，同体重试幂等，旧预览不能覆盖新状态。
- 普通对话每条30天到期，游客7天优先；可提前删除。已确认业务不随删除聊天回滚。导出、注销、游客保存及独立删除清单覆盖新会话数据。
- 长期记忆保持默认关闭；对话内记忆授权、摘要恢复和后台主动调度属于后续范围。

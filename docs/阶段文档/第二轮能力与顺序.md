# 第二轮能力与顺序

依据 PRD V3（FR03、FR04、FR05、FR12）及已确认的 `tasks/plan.md`，先本机实现，不上云、不对外试用。每个子阶段独立验证；产品经理授权不必每次手动验证。

| 能力 | 职责 | 依赖 |
| --- | --- | --- |
| goal-actions | 已确认目标计划步骤的完成、撤销和持久化 | 第一轮计划确认 |
| habit-schedule | 习惯阶段、计划日、打卡及最近3天补签 | 第一轮计划确认 |
| plan-adjustment | 调整提案、前后对比与确认后应用 | goal-actions、habit-schedule |
| growth-pause | 暂停恢复、阶段标准确认及成长 | goal-actions、habit-schedule、plan-adjustment |

实施顺序：goal-actions → habit-schedule → plan-adjustment → growth-pause。具体日期和每周频率不能根据自然语言擅自推断；旧计划不会被自动改写。收藏、站内关心、账号和上线留给已确认的后续轮次。
